# Documentation site toolchain, every package pinned exactly, for Python 3.12.
#
# Ranges let the site change without a commit: between the deploys of 2026-11-18 and a rebuild on
# 2026-11-26 the same ranges resolved mkdocs-material 9.8.1 -> 9.8.2, pymdown-extensions 13.1 ->
# 13.1.2 and Markdown 3.11.3 -> 3.11.4, on CPython 3.15.2 in CI. Material for MkDocs takes only
# critical fixes until its end of life on 2027-05-05, so a later Markdown or pymdown-extensions
# release that breaks it will not be fixed there; a frozen set keeps building.
#
# Zensical is its successor but cannot build this site yet: it silently skips mkdocs-static-i18n and
# `hooks:` (tested with 0.1.3 on 2026-11-26).
#
# To move a pin: change it here, install into a fresh Python 3.12 venv, run `pip check` and
# `mkdocs build`, and compare the output with the previous build.
