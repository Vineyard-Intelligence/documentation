# 플러그인 실행하기

플러그인이 프로젝트에 설치되면 노드의 우클릭 메뉴, 전역 "플러그인 실행" 메뉴, 또는 명령
팔레트의 세 가지 인터페이스 중 하나에서 실행하고, 작업 패널에서 실행을 감시하고
취소할 수 있습니다.

## 플러그인이 어디에 표시되는가

모든 플러그인은 입력을 선언하며, 그 선언이 표시 위치를 결정합니다:

- **노드 유형을 대상으로 함** (예: netblock 노드를 소비하는 IP 주소 확장기) → 일치하는
  노드의 **우클릭 메뉴**에 나타나며, 해당 노드가 입력으로 미리 바인딩됩니다.
- **전체 그래프를 대상으로 함** (예: Chaos 팩의 룰렛들) → 전역 **플러그인 실행** 메뉴
  또는 팔레트에서 실행됩니다.
- **선택을 사용함** → 일부 플러그인은 현재 선택된 노드(들)에 작용하므로, 먼저 노드를
  선택하세요 — 실행이 선택을 입력으로 읽습니다.

## 실행 인터페이스

=== "노드 우클릭"

    플러그인이 소비하는 유형과 일치하는 노드를 우클릭하면 — 플러그인이 메뉴에 표시됩니다.
    선택하면 소비된 노드의 값이 이미 채워진 실행 전 양식이 열립니다.

=== "전역 플러그인 실행 메뉴"

    전체 그래프 플러그인은 붙일 노드가 없으므로 전역 **플러그인 실행** 메뉴에
    대신 표시됩니다.

=== "명령 팔레트"

    팔레트는 플러그인을 이름으로 실행하며, 키보드 우선 작업에 유용합니다:

    - `/plugins` — 현재 프로젝트에 설치된 모든 플러그인을 실행 명령과 함께 나열합니다.
    - `/plugin thanos_snap` — 이름이 지정된 플러그인을 실행합니다. 인수는 플러그인의
      짧은 이름(`run.vineyard.plugins.` 이후 부분) 또는 전체 식별자입니다. 설치되지 않은
      플러그인을 지정하면 마켓플레이스로 안내합니다.

## 실행 전 양식

플러그인이 입력을 받으면 실행 전에 작은 양식이 나타납니다 — 예: CIDR 블록용 텍스트 필드,
또는 한도용 숫자 필드. 필수 필드는 표시되고, 기본값은 미리 채워지며, 입력하는 대로
값이 검증됩니다. 노드에서 실행하면 소비된 값이 미리 채워집니다. 확인하면 실행이
시작됩니다.

## 진행률 및 취소

모든 실행은 **작업**이 되어 작업 패널에 표시됩니다 — 실시간 상태 배지, 플러그인이
보고하는 경우 진행률 막대, 그리고 부분 결과를 버리지 않고 협력적으로 취소하는
**중지** 컨트롤이 있습니다. 상태, 컨트롤, 실행 저장에 대해서는
[작업 및 실행](tasks.md)을 참조하세요.

## Chaos 레퍼런스 팩

Chaos 팩은 실행 루프를 배우기 위해 그래프를 재구성하는 여섯 개의 작은 플러그인을 담은
단일 번들(`run.vineyard.pluginpacks.chaos`)입니다:

| 플러그인 | 하는 일 |
|---|---|
| Korean Roulette | 임의의 노드 하나를 유지하고 나머지 모두 삭제 |
| Russian Roulette | 임의의 노드 하나 삭제 |
| Thanos Snap | 노드의 절반을 무작위로 삭제 |
| Black Hole | 선택된 노드의 1-홉 이웃 삭제 |
| Dumb AI Optimizer | 몇 초간 가짜 진행 표시, 아무것도 변경하지 않음 |
| Schrödinger's Node | 임의의 노드 선택; 50% 삭제 / 50% 아무것도 안 함 |

!!! tip "안전하게 시도하세요"
    Chaos 팩은 의도적으로 파괴적입니다. 실제 작업을 잃지 않도록 폐기용 그래프에서
    실행하여 Korean Roulette, Thanos Snap, Black Hole이 캔버스를 재구성하는 것을
    지켜보세요.
