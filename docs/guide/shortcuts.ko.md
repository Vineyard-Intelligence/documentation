# 단축키

피벗은 같은 몇 단계의 반복입니다. 노드를 선택하고, 선택을 한 홉 넓히고, 그 선택에 플러그인을 실행하고, 찾은 것을 리뷰합니다. 이 단계마다 키가 있어서 키보드에서 손을 떼지 않고 작업할 수 있습니다.

키는 Mac 기준으로 적었습니다. Windows와 Linux에서는 이 페이지의 **Cmd**(⌘) 대신 **Ctrl**을 누르세요.

## 키가 동작하는 곳

- **입력하는 동안에는 동작하지 않습니다.** 입력란에서 단일 키는 그 글자를 입력합니다. 입력란 자신의 키 말고 입력란에서 동작하는 것은 **Esc**, 검색란의 ++cmd+g++, AI 에이전트 입력란의 ++arrow-up++, 리뷰 대화상자의 ++cmd+enter++뿐입니다.
- **캔버스 키는 캔버스에서 동작합니다.** 캔버스를 클릭하거나 ++g++ 다음 ++c++를 누르면 캔버스 키가 캔버스에 동작합니다. 캔버스에 키보드 포커스가 있으면 얇은 파란 테두리가 보입니다. 아직 아무 곳도 클릭하지 않았을 때도 동작합니다. Properties 패널, 메뉴 바, 떠 있는 패널, 대화상자에서 누른 키나, 그곳을 클릭한 직후에 누른 키는 그래프를 건드리지 않습니다. Properties 패널에서 값을 편집한 뒤 ++backspace++를 눌러도 선택이 지워지지 않습니다.
- **한글 입력.** 한글 입력 소스에서도 키는 키보드의 자리로 동작합니다. ㄹ을 입력하는 키가 ++f++이고, ++g++ 다음 ++a++는 ㅎ을 입력하는 키 다음 ㅁ을 입력하는 키입니다. 한글 음절을 끝내는 키는 음절만 끝냅니다.
- **에이전트가 일하는 동안.** AI 에이전트의 입력란은 에이전트가 일하는 동안 잠깁니다. 그동안 친 키는 얼마나 기다리든 어딘가를 클릭하거나 ++tab++으로 옮길 때까지 단축키로 받지 않습니다. **Esc**와 **Cmd/Ctrl** 단축키는 그대로 동작합니다. 에이전트가 끝나면 커서가 입력란으로 돌아갑니다. 그사이에 다른 곳을 클릭했다면 돌아가지 않습니다.
- **단일 키 끄기.** **Settings → General → Keyboard → Single-key shortcuts**를 끄면 글자 하나로 된 단축키(F, N, /, [ 등)와 **G 다음 글자** 키가 모두 꺼집니다. 받아쓰기를 쓸 때 등에 끄세요. **Esc**, **Enter**, 화살표 키, **Delete**, **Cmd/Ctrl** 단축키는 켜진 채로 남습니다. 이 설정은 **This device only**입니다.

## 어디서나

| 키 | 동작 |
| --- | --- |
| ++cmd+f++ 또는 ++slash++ | **Search entities…**로 이동합니다. |
| ++cmd+g++ / ++shift+cmd+g++ | 다음 / 이전 검색 결과로 이동해 선택하고 가운데에 놓습니다. 검색란에 무언가 입력되어 있을 때 동작합니다. 검색란 안에서도, 다른 입력란 밖이면 어디서나 됩니다. |
| ++cmd+comma++ | Settings를 엽니다. |
| ++esc++ | 앞에 있는 것을 한 번에 하나씩 닫습니다. 더 닫을 것이 없으면 선택을 해제합니다([캔버스](canvas.md#right-click-menus) 참조). |

## 이동

++g++를 누르고 1초 안에 두 번째 키를 누릅니다.

| 키 | 이동할 곳 |
| --- | --- |
| ++g++ 다음 ++a++ | AI 에이전트의 입력란. 패널이 닫혀 있으면 새 대화를 엽니다. |
| ++g++ 다음 ++c++ | 캔버스. |
| ++g++ 다음 ++p++ | Properties 패널의 첫 칸. |
| ++g++ 다음 ++t++ | Types 패널의 검색란. 패널이 아이콘으로 접혀 있으면 첫 타입. |
| ++g++ 다음 ++k++ | Tasks 패널. |
| ++g++ 다음 ++s++ | 프로젝트 설정. |
| ++g++ 다음 ++m++ | Marketplace. **Project** 메뉴에 이 항목이 있을 때. |

## 캔버스

| 키 | 동작 |
| --- | --- |
| ++f++ | **Fit view**처럼 그래프 전체를 화면에 맞춥니다. |
| ++shift+f++ | 선택을 화면에 맞춥니다. 노드 하나는 150%로 가운데에 놓습니다. |
| ++equal++ 또는 ++plus++, ++minus++ | 툴바 버튼처럼 확대, 축소합니다. 누르고 있으면 계속됩니다. |
| ++0++ | 100%로 맞춥니다. |
| 화살표 키 | 보기를 옮깁니다. ++shift++를 함께 누르면 더 크게 옮깁니다. |
| ++l++ | **Layout** 메뉴를 엽니다. ++arrow-down++로 첫 레이아웃에 가고 ++enter++로 고릅니다. |
| ++shift+l++ | 지금 레이아웃으로 다시 배치합니다. 노드를 놓아 둔 위치는 풀립니다. |

## 선택

| 키 | 동작 |
| --- | --- |
| ++cmd+a++ | 모든 노드를 선택합니다. |
| ++n++ | 연결된 이웃까지 선택을 넓힙니다. 누를 때마다 한 홉씩. |
| ++bracket-left++ / ++bracket-right++ | 들어오는 쪽 / 나가는 쪽으로 선택을 넓힙니다. 누를 때마다 한 홉씩. |

**Invert selection**, **Select isolated nodes**, **Clear selection**에는 따로 키가 없습니다. 선택 해제는 **Esc**입니다.

## 선택한 대상

| 키 | 동작 |
| --- | --- |
| ++r++ | 선택에 대해 **Run plugins**를 엽니다. 아무것도 선택하지 않았으면 프로젝트 전체에 대해 엽니다. |
| ++a++ | 선택에 대해 AI 에이전트에게 묻습니다. 질문이 채워진 새 대화가 열리고, 질문은 보내지 않습니다. 대화가 이미 열려 있으면 새 대화 대신 그 입력란으로 가고, 입력란이 비어 있을 때만 질문을 채웁니다. 쓰던 질문은 그대로 남습니다. |
| ++c++ | **Connect to…**: 선택을 연결할 노드를 클릭합니다. |
| ++enter++ 또는 ++f2++ | 선택한 노드의 값을 Properties 패널에서 편집합니다. 노드 라벨이 보여 주는 칸입니다. 엣지는 relation 칸입니다. |
| ++backspace++ 또는 ++del++ | 선택을 삭제합니다. **Delete (N)**과 같은 확인 창이 **Cancel**에 포커스를 둔 채 열립니다. |

**Duplicate**와 에이전트 턴 중지에는 키가 없습니다. 잘못 친 키로 일어나지 않게 하기 위해서입니다.

## AI 에이전트 패널

| 키 | 동작 |
| --- | --- |
| ++enter++ / ++shift+enter++ | 보내기 / 줄바꿈. |
| ++arrow-up++ | 입력란이 비어 있을 때, 마지막으로 한 질문을 다시 불러와 고쳐서 보낼 수 있게 합니다. |
| ++esc++ | 패널을 닫습니다. 실행 중인 턴은 계속됩니다([작업 및 실행](tasks.md#closing-and-deleting-a-conversation) 참조). |

## 리뷰 대화상자

| 키 | 동작 |
| --- | --- |
| ++arrow-up++ ++arrow-down++, ++arrow-left++ ++arrow-right++ | 행 이동, 페이지 넘기기. |
| ++space++ | 포커스가 있는 행을 체크하거나 해제합니다. |
| ++slash++ | **Filter by keyword**로 이동합니다. |
| ++cmd+enter++ | 체크한 변경을 **Apply**합니다. **Why reject?** 입력란에서도 동작합니다. **Apply** 버튼이 있고 적용할 것이 있을 때만 동작합니다. |
| ++esc++ | 대화상자를 닫습니다. 실행과 체크 상태는 남습니다([플러그인 실행](running-plugins.md#reviewing-a-runs-changes) 참조). |

## Properties 패널

| 키 | 동작 |
| --- | --- |
| ++tab++ / ++shift+tab++ | 다음 / 이전 칸. |
| ++enter++ | 한 줄 칸을 저장합니다. |
| ++cmd+enter++ | 여러 줄 칸을 저장합니다. |
| ++esc++ | 칸을 저장된 값으로 되돌립니다. |

## 웹 브라우저에서

브라우저가 직접 쓰는 키가 있고, Vineyard는 그 키를 가져가지 않습니다. 새 탭과 새 창, 닫기, 새로고침, 주소창, 페이지 확대(++cmd+plus++, ++cmd+minus++, ++cmd+0++), 개발자 도구입니다. Mac에서는 ++cmd+comma++가 브라우저 자신의 설정을 열 수 있습니다. 아바타 메뉴의 Settings 항목은 언제나 동작합니다. 한영 전환에 쓰는 키는 어떤 단축키로도 쓰지 않습니다.
